# AI Studio v3 · 漫剧工作台

从一句话创意 / 小说 / 剧本，到带对白配音、字幕和配乐的成片。单卡 32GB 本地全流程运行。

```
① 剧本 ──▶ ② 角色与场景（设定 + 参考图）──▶ ③ 分镜表 ──▶ ④ 分镜图（多图参考）──▶ ⑤ 镜头视频 ──▶ ⑥ 成片
 Qwen3.6         Qwen3.6 + Qwen-Image 2.1         Qwen3.6      Qwen-Image 2.1          MiniMax H3     ffmpeg
```

| 环节 | 模型 | 说明 |
|---|---|---|
| 文字（剧本/提取/分镜） | Qwen3.6-35B-A3B Q4_K_M（llama.cpp） | 全流程只用这一个文字模型；也可切换到任意 OpenAI 兼容 API |
| 图片 | Qwen-Image 2.1 Turbo | 文生图 + 最多 16 张参考图。分镜图会把镜头里**每个角色的参考图 + 场景图**一起输入，多人镜头不再串脸 |
| 视频 | MiniMax H3 | 图生视频（分镜图作首帧）/ 参考生视频，**同时生成对白、音效** |
| 人脸工具 | FaceFusion 3.9 | 换脸、修脸、口型、年龄、背景移除等 10 种处理 |
| 成片 | ffmpeg | 拼接、字幕（自动由台词生成）、背景音乐 |

### 角色一致性（三层保障）

1. **定妆照 + 脸部特写**：每个角色一张全身定妆照（锁服装体型），再由定妆照派生一张脸部特写（锁五官）。首次生成定妆照时自动出特写；换了定妆照会提示重新生成。
2. **多图参考出图**：分镜图 / 指令改图 / 参考生视频，都会把出镜角色的「全身 + 特写」和场景图一起作为参考，并在提示词里写明「脸型以特写为准，服装以全身为准」。名额不够时优先保证每个角色至少一张。
3. **人脸修正**：分镜图或视频里个别镜头脸走样 / 串脸，点「人脸修正」即可用角色特写做 FaceFusion 换脸（HyperSwap + 面部增强）。单人镜头自动选最大的脸；多人镜头按从左到右的位置逐个替换。结果保存为新版本，可随时切回。

### 质量与配音（v3.1）

- **访问密码**：`05_app.sh` 自动生成随机密码写入 `.env` 的 `ACCESS_PASSWORD`（启动时会打印），打开网页先登录；留空则不需要密码。
- **自动质检 + 重抽**：每张分镜图、每段视频生成后自动检查①是否冒出参考图里没有的文字/乱码字幕（RapidOCR）②人物脸和角色特写是否一致（ArcFace，仅写实画风）。不合格自动换种子重抽（`QA_VIDEO_RETRY` / `QA_KEYFRAME_RETRY` 次），挑最好的一版；结果显示在缩略图上。
- **道具一致性**：提取角色时一并提取关键道具（信物、照片、信件…），生成道具参考图；分镜表标注每个镜头出现的道具，出图时作为参考图输入。
- **固定音色配音 + 对口型**（`bash deploy/06_voice.sh` 安装）：
  1. 角色卡上「生成音色样本」（H3 按声音描述说一句话并提取人声）或上传自己的录音；
  2. 镜头视频页「配音」：IndexTTS2 用音色样本合成台词（同一角色每个镜头都是同一个声音，支持情绪）→ Demucs 去掉原视频里的人声、保留环境音 → 单人中近景自动用 LatentSync 1.6 对口型（其他镜头可手动强制）；
  3. 剧本页勾选「配音模式」后，生成视频时 H3 只出环境音，视频生成完自动配音。
- **一键成片**：左侧栏「🚀 一键成片」（或新建项目时选择），按 剧本 → 角色与场景 → 参考图 →（音色）→ 分镜表 → 分镜图 → 动态分镜预览 → 视频 →（配音）→ 合成 自动推进；已完成的步骤跳过、只补缺失；默认在剧本、分镜表、动态分镜预览后停下审核（可改），失败步骤自动重试一次；侧栏显示当前步骤、剩余镜头和预计剩余时间。
- **动态分镜预览**：③分镜页把分镜图按运镜做推拉摇移动画、叠加台词字幕，按镜头时长拼成预览片（十几秒生成），可选角色音色试听；面板里直接改时长、调顺序。
- **镜头衔接与首尾帧**：分镜表自动标出「与上一镜连续动作」的镜头（③分镜里可勾选修改）；连续镜头的视频首帧取上一镜视频的最后一帧（人脸不像时自动用 FaceFusion 修正），批量生成时自动排在上一镜之后；上一镜重做后④视频页提示本镜需重生成。每个镜头可设「尾帧」（AI 按镜头内动作生成或上传），视频走首尾帧模式让动作落到位。
- **失败自动恢复**：显存不足 → 释放显存重试，第二次自动降级（草稿/Turbo/少出几张）；ComfyUI 崩溃或卡死 → 自动重启（`deploy/start_comfyui.sh --restart`）后重试；文字模型掉线 → 重启后重试；每个任务最多自动重试 2 次。服务重启时中断的任务自动重新排队。失败信息改为中文原因 + 处理建议（原始错误附在后面）。
- **任务调度**：队列按模型分组（出图 / 视频 / 配音）连续执行，减少大模型来回加载；同项目按依赖顺序执行；手动任务优先于批量；任务中心可「暂停排队 / 继续」。

### 创作、后期与发布（v3.2，路线图阶段 2–4）

标 🖥️ 的需要显卡实测验收（见 `docs/ROADMAP.md` 执行表），其余已在无卡环境测试通过。

- **编剧室**：题材模板、节拍表（钩子/反转/爆点节奏）、大纲 → 分集 → 台词打磨，人物动机/关系/口头禅写进提示词。
- **导演审校**：分镜表一键审校（景别节奏、越轴、台词塞不下、转场），建议逐条接受/拒绝。
- **美术 / 选角** 🖥️：角色设定图（多视角/表情）、服装造型、场景变体、画风参考图 / LoRA、角色库跨项目复用。
- **分镜增强** 🖥️：构图站位、姿势参考、局部重绘；**视频增强** 🖥️：运镜方向/速度、运镜 LoRA、动作参考视频。
- **视觉审片** 🖥️：本地视觉大模型逐镜头打分（人物、动作、穿帮），一键返工；整片审片报告。
- **调色统一 / 去闪烁**、**字幕与包装**（字幕样式、片头片尾卡、封面）。
- **声音后期**：旁白（三种解说风格）、音效库自动匹配、人声闪避、响度标准化（-14 LUFS）、AI 配乐 ACE-Step 🖥️。
- **超分 / 补帧** 🖥️：Real-ESRGAN / SeedVR2 超分到 1080p/1440p，RIFE 补帧到 48/60fps。
- **导出工程**：剪映草稿（分轨：画面/对白/旁白/环境音/音效/配乐/字幕）、FCPXML、EDL、SRT 打包 zip。
- **多集与系列**：长篇小说 AI 分集规划，新集继承风格和全部角色/场景/音色，自动前情摘要，批量一键成片。
- **多比例导出**：成片一键出 9:16 / 16:9 / 1:1 版本，逐镜头分析主体后智能裁切跟随或模糊垫底（可手调）；或复制为新画幅项目重新出图。
- **云端混合**（可选）：海螺 / 可灵作为视频引擎，按镜头或按比例分配，与本地显卡并行出片，重试不重复扣费。
- **运维与统计**：任务耗时（P50/P90）与成功率、失败原因、磁盘占用与清理（只删未选用的候选）、项目备份与恢复。

## 和旧版相比

- **重写**：旧版 `main.py` 2.7 万行（34 个函数被重复定义 58 次）、分镜 1.1 万行审计逻辑，全部替换为后端约 2,500 行 + 前端约 1,000 行的清晰实现。
- **修复多人镜头出图问题**：旧版出图时用叙事句覆盖了提示词、角色设定从未传给出图模型、只能纯文生图。现在每个镜头的提示词 = 景别机位 + 画面描述 + `<imageN>` 角色参考 + 场景参考 + 人数约束 + 画风，并且**在界面里可以预览实际发送给模型的完整内容**。
- **去掉僵化审计**：分镜只做必要的格式校验（景别/机位取值、角色名对齐、台词时长估算），不再反复改写。
- **任务中心**：所有生成都排队执行，可取消、重试，服务重启后可恢复。
- **候选挑选**：角色图、场景图、分镜图、视频都保留历史候选，点一下切换；支持上传自己的图片/视频替换；分镜图支持「指令改图」。

## 快速开始

见 [docs/DEPLOY.md](docs/DEPLOY.md)。简版：

```bash
cd /root/autodl-tmp/ai-studio
bash deploy/install_all.sh          # 加 --voice 同时安装配音/对口型（也可之后单独 bash deploy/06_voice.sh）
/root/autodl-tmp/envs/studio/bin/python scripts/preflight.py --smoke
# AutoDL 控制台 → 自定义服务 → 打开 6006
```

## 本地开发

```bash
pip install -r requirements.txt pytest
pytest -q                                   # 模拟文字模型和 ComfyUI，跑完整流程（需要 ffmpeg）
uvicorn app.main:app --port 6006 --reload
```

# AI Studio 优化路线图（对齐国内成熟产品）

> 目标：对齐即梦 / 可灵 / 海螺 / Vidu 及主流漫剧工具的成片水准。
> 先做到**稳定、较快地出片**，再补齐**编剧 / 导演 / 分镜 / 审片**的专业能力，最后把**成片品质**和**批量交付**做完整。
> 本文件是后续开发的唯一依据：每完成一项，把 `[ ]` 改成 `[x]`，并在「变更记录」追加一行。

## 0. 现状基线（2026-10-21，RTX 4090 D 24GB，v3 分支）

| 指标 | 现状 | 阶段目标 |
|---|---|---|
| 5 秒视频（草稿 864×480） | ≈ 144 秒 | ≤ 70 秒 |
| 5 秒视频（成品 1344×768） | 约草稿的 3~4 倍 | ≤ 草稿的 2 倍 |
| 1 分钟 / 13 镜头成片全流程 | ≈ 45 分钟（视频占 31 分钟） | ≤ 20 分钟 |
| 成片分辨率 / 帧率 | 864×480 或 1344×768 / 24fps | 1080p（可选 2K）/ 24~60fps |
| 分镜图 | ≈ 29 秒 / 张 | ≤ 20 秒 / 张 |
| 已有能力 | 剧本、角色/场景/道具参考图、分镜表、多图参考分镜图、H3 图生视频、人脸修正、自动质检重抽（乱码字幕、人脸一致）、固定音色配音、对口型、访问密码 | |

状态标记：✅ 已有｜⚠️ 粗糙｜❌ 没有。🖥️ = 需要开 GPU 实测；📝 = 纯代码，可无卡开发。

## 阶段 1：稳定 + 提速（先保证“能正常、较快地出片”）

### P1-1 推理加速 🖥️
- **做法**
  - ComfyUI 启动参数：`--use-sage-attention`（SageAttention 2，安装 `sageattention` wheel）；实测 `--fast fp16_accumulation` / FP8 矩阵加速。
  - 视频 DiT 推理缓存（TeaCache / MagCache / EasyCache 类节点，H3 适配后开启），草稿默认开、成品可关。
  - 记录每类任务耗时到任务结果，系统状态页显示平均耗时。
- **验收**：同一镜头同种子，草稿 5 秒视频 ≤ 70 秒；画质肉眼无明显下降（并排对比图存档）。

### P1-2 任务调度优化 📝
- **做法**
  - 队列按「模型组」聚合：出图类（定妆照/场景/道具/分镜图）与视频类分别连续执行，减少 Qwen-Image ↔ H3 来回加载。
  - 同类任务优先级：用户手动触发 > 批量任务；批量任务可整体暂停。
  - 模型切换次数、加载耗时写日志。
- **验收**：13 镜头“批量分镜图 + 批量视频”只发生 1 次模型切换。

### P1-3 一键成片流水线 📝
- **做法**：新增「一键成片」任务链：剧本 → 提取 → 参考图 → 分镜表 → 分镜图 → 动态分镜预览 → 视频 → 配音 → 后期 → 合成。
  - 每个节点可设为「自动继续」或「停下等我审核」（默认在剧本、分镜表、动态分镜预览三处停）。
  - 进度面板显示当前节点、剩余镜头、预计剩余时间。
- **验收**：从一句创意出发，不手动点任何按钮即可得到成片；中途审核点能修改后继续。

### P1-4 失败自动恢复 📝🖥️
- **做法**：显存不足（OOM）、ComfyUI 崩溃、llama-server 掉线时自动重启对应服务并重试（最多 2 次）；服务重启后排队任务自动续跑；失败原因翻译成中文建议。
- **验收**：人为 kill ComfyUI，正在跑的任务自动恢复并完成。

### P1-5 动态分镜预览（Animatic） 📝
- **做法**：分镜图 + 配音（或 TTS 试听）+ 字幕 + 推拉摇移的 Ken Burns 动画，按分镜时长拼成预览片（几十秒内生成）；确认后再出视频。
- **验收**：13 镜头预览片 ≤ 1 分钟生成；可在预览里直接调整镜头时长和顺序。

### P1-6 镜头衔接与首尾帧 📝🖥️
- **做法**
  - H3 fl2va 首尾帧模式：分镜表中标记「连续动作」的相邻镜头，下一镜首帧 = 上一镜尾帧（抽取最后一帧并修脸）。
  - 可为镜头指定尾帧图（分镜图生成第二张“结束姿态”），让动作有确定终点。
- **验收**：连续动作的两镜拼接处人物位置、服装、光线不跳变。

## 阶段 2：专业创作（编剧 / 美术 / 导演 / 分镜 / 审片）

### P2-1 编剧室 📝
| 能力 | 现状 | 做法 |
|---|---|---|
| 题材 / 平台模板 | ❌ | 竖屏短剧、漫剧解说、爽文逆袭、悬疑、甜宠、古风等模板：结构、节奏、台词风格、禁忌 |
| 节拍表 | ❌ | 先出节拍表（3 秒钩子 → 冲突升级 → 反转 → 结尾卡点），确认后再写剧本 |
| 小说改编 / 多集 | ❌ | 长文本按章节拆集 → 分集大纲 → 分集剧本；保留前情摘要保证连续 |
| 人物小传 | ⚠️ | 人设卡：性格、动机、关系、口头禅、说话方式，后续所有环节引用 |
| 台词打磨 | ⚠️ | 口语化、按镜头时长控制字数（≈ 4 字/秒）、去书面腔 |
| 审稿改稿 | ❌ | 评分卡（钩子强度、冲突、节奏、逻辑、人设一致、台词）逐项打分 + 修改意见，低于阈值自动改稿（最多 2 轮），显示前后对比 |
- **验收**：同一创意，新版剧本评分卡 ≥ 80 分；钩子出现在前 3 秒；每集结尾有卡点。

### P2-2 美术 / 选角 📝🖥️
- 角色三视图（正 / 侧 / 背）+ 表情表（喜怒哀惊等 6 种），按镜头景别和朝向挑选参考图。
- 多套服装：角色可有多个造型，分镜表按场次指定造型。
- 场景多角度（正反打两个方向）+ 日 / 夜 / 雨等变体。
- 风格锁定：项目级风格参考图（可选风格 LoRA），所有出图统一画风。
- 角色库：角色 / 场景 / 道具跨项目复用（系列剧）。
- **验收**：侧脸、背影、正反打镜头中人物和背景一致性明显提升（质检人脸相似度均值提升）。

### P2-3 导演审校 📝
- 镜头语言规则引擎 + LLM 导演：轴线（180° 规则）、视线匹配、景别交替（避免连续同景别）、对话正反打、场景开头建立镜头、动作接剪。
- 每镜表演指导：表情、动作节拍、视线方向。
- 节奏设计：情绪曲线 → 镜头时长快慢；转场方式（硬切 / 叠化 / 闪白 / 匹配剪辑）。
- 输出「导演批注」并自动修正分镜表，可逐条接受 / 拒绝。
- **验收**：规则检查零违规；人工评审分镜表专业度明显提升。

### P2-4 分镜增强 📝🖥️
- 构图 / 姿势控制：姿势参考图（OpenPose / 深度）、指定人物在画面中的位置和大小。
- 局部重绘：框选区域重画（手、道具、表情）。
- 多版本对比视图：同一镜头候选并排对比、一键选用。
- **验收**：可以把指定角色放到画面左 1/3 处并保持身份；局部重绘不影响其余画面。

### P2-5 视频生成增强 🖥️
- 运镜控制：推 / 拉 / 摇 / 移 / 环绕 / 跟拍有可靠的实现方式（提示词模板 + 可选运镜 LoRA / 参考视频）。
- 视频延长：基于尾帧续写，支持长镜头。
- 动作参考：用参考视频驱动人物动作（可选）。
- **验收**：运镜指令符合率 ≥ 80%（审片模型判定）。

### P2-6 视觉大模型审片 🖥️
- 引入视觉语言模型（如 Qwen3-VL 8B，llama.cpp 或 ComfyUI 加载），对分镜图 / 视频抽帧审查：
  - 人数、角色是否正确；动作 / 表情是否符合描述；
  - 手指 / 肢体畸形、穿帮、道具是否一致、画面是否崩坏 / 闪烁；
  - 音画核对：语音识别对比台词，检查口型 / 字幕是否对得上。
- 不合格：给出原因 → 自动改提示词重抽，或交给用户确认。
- 整片审片报告：逐镜打分 + 问题清单 + 一键返工。
- **验收**：人工标注的 30 个坏镜头检出率 ≥ 80%，误报率 ≤ 15%。

## 阶段 3：成片品质（后期）

### P3-1 超分 🖥️
- 写实：SeedVR2（3B FP8，24GB 可跑），输出 1080p / 2K；漫剧 / 动漫：Real-ESRGAN animevideov3（快）。
- 只对“已选定”的镜头执行；结果作为新版本保存。
- **验收**：1080p 成片细节清晰、无明显涂抹；每 5 秒镜头耗时有记录（目标 ≤ 3 分钟）。

### P3-2 补帧 🖥️
- RIFE 补帧到 48 / 60fps（可选），慢动作镜头支持 2× 慢放。
- **验收**：快速动作无明显鬼影。

### P3-3 调色统一 / 去闪烁 📝
- 以选定的“基准镜头”做色彩匹配（直方图 / LUT），全片色调统一；可选风格 LUT（电影、清新、赛博等）。
- 时域去闪烁（deflicker），必要时防抖。
- **验收**：相邻镜头色温 / 亮度差明显减小（量化指标：平均 Lab 差值）。

### P3-4 字幕与包装 📝
- 字幕样式：字体、描边、阴影、位置、逐字高亮（卡拉 OK 式）、花字强调关键词。
- 转场、片头片尾、标题卡、集数卡。
- 封面图生成（选高光帧 + 标题字）。
- **验收**：成片包装达到主流短剧平台常见水准。

### P3-5 声音后期 📝🖥️
- 旁白 / 解说配音（漫剧解说体）。
- AI 配乐：ACE-Step 按情绪曲线生成 BGM，自动对齐剪辑点。
- 音效补充（脚步、开门、雨声等音效库 / 生成）。
- 混音：人声出现时自动压低 BGM（ducking），整片响度统一到 -14 LUFS。
- **验收**：无爆音、无忽大忽小；BGM 不盖过台词。

## 阶段 4：交付与系列化

### P4-1 导出剪映草稿 📝
- 导出剪映草稿（视频轨、配音轨、BGM 轨、字幕轨分开），也可导出 FCPXML / EDL。
- **验收**：剪映打开后各轨道齐全、时间线一致。

### P4-2 多集与系列 📝
- 项目下多集；前情摘要；角色库共享；批量生产多集。

### P4-3 多比例导出 📝
- 同一项目导出 9:16 / 16:9（智能裁切或重新出图）。

### P4-4 云端混合（可选） 📝
- 接入海螺 / 可灵等云端视频接口作为可选引擎，按镜头选择本地或云端，并行加速。

### P4-5 运维与统计 📝
- 耗时 / 成功率统计、磁盘清理（删除未选用候选）、一键备份项目。
